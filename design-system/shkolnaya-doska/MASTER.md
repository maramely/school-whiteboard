# Интерактивная доска — визуальный стиль (MASTER)

Референс: Apple Freeform на iPad — лёгкая типографика, компактные плавающие панели, рисование пальцем. Применены принципы скилла Apple Design (мгновенный отклик на нажатие, материалы, origin-aware поповеры, reduced motion/transparency/contrast).

## Палитра (холодные цвета школьного Storybook)
| Токен | Значение | Роль |
|---|---|---|
| `--bg` | #FAFAFC (ghostWhite) | общий фон |
| `--canvas` | #FFFFFF (white) | полотно |
| `--lav` | #EBEBF4 (violetBg) | светлые подложки, главная кнопка |
| `--lav-2` / `--lav-3` | #E1E1EE / #D7D7E8 | наведение, выбранный инструмент / нажатие |
| `--accent` | #5854A4 (digitalViolet) | акценты, фокус, ссылки (6.5:1) |
| `--ink` / `--ink-2` | #27205D (darkBlue) / #5E5A7E | текст и иконки / вторичный текст |
Без градиентов. Главная кнопка — однотонная violetBg, тёмная полужирная подпись, скругление 14 px, без тени и обводки; наведение и нажатие — чуть темнее заливка; фокус с клавиатуры — контур digitalViolet 3 px. Иконка «Создать доску» — контурный карандаш (тот же набор, 20 px, цвет текста). Палитра пера отдельная (10 ярких цветов).

## Типографика
Системный шрифт (SF на Mac и iPad). Подписи — 400, ключевые действия — 600. Заголовок доски 15/600, крупные заголовки с отрицательным трекингом (-0.022em).

## Компоненты
- Шапка: «‹» · название · [Пригласить | Загрузить задание | Инструкция] · [участники | RU EN] · «•••» · «Завершить урок» (отдельно, с подписью). Ученик видит только инструкцию, участников и язык.
- Подписи в шапке рендерятся на двух языках в одной ячейке → ширина не меняется при переключении.
- Док: отменить · повторить · перо · кружок текущего цвета · ластик. Выбранный инструмент — мягкая сиреневая подложка. Иконки одной толщины (1.8).
- Приглашение — поповер у кнопки без затемнения; «Копировать ссылку» → «Скопировано».
- Модальные окна с затемнением — только для подтверждений.
- Цели касания ≥ 44×44, анимации 120–240 мс без отскока; reduced motion → без движения, reduced transparency → сплошной белый.
